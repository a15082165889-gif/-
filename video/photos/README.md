# Your own photos

The film uses real stand-in footage. To put your own picture into the old-photograph scene in
Chapter One, save it here as:

| File                          | Where it appears                                  |
|-------------------------------|---------------------------------------------------|
| `childhood.jpg` (or `.png`)   | The aged print on the table ("age 5"), Chapter One |

Then rebuild with `python3 build.py`. The picture is cropped to 4:3, toned like an old print and
given the handwritten "age 5" caption automatically.
